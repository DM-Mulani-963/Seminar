# MEC-Privacy-Simulator

Interactive 3D simulation of a Location Privacy-Aware Task Offloading system in Mobile Edge Computing (MEC). The project visualizes how mobile users securely offload computational tasks to edge servers while preserving location privacy through Differential Privacy-based perturbation mechanisms and adaptive offloading strategies.

## Overview

MEC-Privacy-Simulator demonstrates the relationship between:

- Mobile Users
- Edge Servers
- Task Offloading
- Differential Privacy
- Location Perturbation
- Privacy Leakage
- Computation Cost
- Multi-Server Collaboration
- Real-Time Decision Making

The simulation provides an immersive 3D environment for understanding privacy-preserving task offloading in modern edge computing systems.

## Key Concepts

### Mobile Edge Computing (MEC)

Mobile devices offload computation-intensive tasks to nearby edge servers to reduce:

- Processing delay
- Energy consumption
- Device workload

### Location Privacy Protection

The simulator demonstrates how user location information can be protected from:

- Malicious servers
- Curious edge nodes
- Inference attacks
- Multi-server collusion

### Differential Privacy

Privacy is preserved through controlled location perturbation that prevents accurate user tracking while maintaining system efficiency.

### Adaptive Task Offloading

The simulator visualizes intelligent task distribution based on:

- Server availability
- Channel conditions
- Privacy requirements
- Resource utilization
